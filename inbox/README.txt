这个文件夹是**小米导出包的固定落点**，也是导入器搜索的第一站。

正常流程你什么都不用做：双击项目根目录的 `从邮箱导入.cmd`（或总控台「运行项目」→
绿色按钮），它会取回最新一封邮件的解压密码，用脚本自己的浏览器把包下载到
这里、导入。看板内发起时会显示导入进度并自动更新页面；命令行直接导入时结果显示在命令行。

导入成功后，这里以及 `D:\网页下载` 里其它的小米旧包会被自动清掉 ——
**最终只保留最新一份**。非小米的下载文件不会被碰。

手动导入只剩命令行这一种（2026-09-24 起窗口里的「拖 zip + 输密码」已移除）：
    python tools\import_zip.py inbox\<包文件名>.zip
密码在提示时输入（每次导出都会变，不保存）。

导入器**只找项目内的目录**（2026-09-24 收敛）：
    本项目 inbox → 本项目 latest

以前还会去 `D:\网页下载` 和系统下载目录里翻，代价是：清掉状态后「上次导入时间」归零，
外面任何一个刚下载的 zip 都会被当成最新的导出包（实测真的选中过一个无关的 archify.zip）。
自动下载的落点本来就是本项目 inbox，没必要再去外面找。

命令行手动导入不受影响：传的是显式路径，不走这套搜索；
但如果你是在浏览器里手动下载，请把 zip 放进本文件夹。

导入是全量重建；解压密码只在内存里过一趟，不会落盘（每次导出密码都会变）。
